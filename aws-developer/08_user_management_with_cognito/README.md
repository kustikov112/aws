# User Management with Cognito

# Goal

- Learn how to manage users in a serverless application
- Explore AWS Cognito User Pools and their configuration
- Integrate Cognito with existing Lambda functions

# Topics

- Authentication vs Authorization overview (recap)
- AWS Cognito overview
- Cognito User Pools — creation and configuration
- App Clients and OAuth 2.0 flows
- JWT tokens — structure, validation, and claims
- Lambda triggers (post-confirmation, pre-token generation)
- Storing user attributes in DynamoDB
