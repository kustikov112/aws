# AI Media Enrichment (Bonus Module)

# Goal

- Learn how to integrate AWS AI services into an existing serverless application
- Use Amazon Rekognition to analyze uploaded photos automatically
- Store AI-generated metadata and surface it through the API and frontend

# Topics

- AWS AI/ML services overview (Rekognition, Textract, Comprehend)
- Amazon Rekognition — image analysis APIs (DetectLabels, DetectText, DetectModerationLabels)
- Triggered enrichment pipelines with Lambda and S3 events
- Storing enrichment metadata in DynamoDB
- Extending existing APIs to return AI-generated attributes
