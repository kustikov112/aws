# Frontend Authentication with Cognito

# Goal

- Add user authentication to the MapPoints SPA
- Integrate the Cognito Hosted UI with a React application
- Handle JWT tokens securely on the client side

# Topics

- Cognito Hosted UI overview
- OAuth 2.0 Authorization Code flow
- Handling callback redirects and extracting tokens
- Storing tokens in the browser (localStorage vs sessionStorage)
- Protecting UI routes and API calls with JWT tokens
- Logout and token revocation
